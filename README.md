# ASD Elementary Coding Competition 2026

**Theme:** Secrets of the Sea: Unlock the Code
**Deadline:** March 27, 2026
**Platform:** [CodeHS](https://codehs.com)

## Requirements

- Ocean-themed content with interactive elements
- Multiple levels or scenes
- At least one comment per sprite explaining the code
- Instructions for how to run your program
- Source citations for any images/sounds used
- **No AI-generated code, images, or backgrounds**

## Interactive Elements (pick at least one)

- Sprite clicks (click on something to make it do something)
- Key responses (press arrow keys to move)
- Mouse-following (sprite follows your cursor)

## Project Ideas

### Beginner
- **Ocean Quiz Game** - Click on the correct sea creature to answer questions
- **Submarine Explorer** - Use arrow keys to navigate a submarine and collect treasure

### Intermediate
- **Avoid the Jellyfish** - Control a fish, dodge jellyfish, collect points
- **Underwater Maze** - Guide a diver through a coral reef maze

### Advanced
- **Ocean Cleanup** - Multiple levels, collect trash while avoiding sharks
- **Pirate Treasure Hunt** - Story-based game with clues and puzzles

## Tips

1. **Plan first** - Sketch your game on paper before coding
2. **Start simple** - Get one thing working, then add more
3. **Test often** - Run your code after each change
4. **Comment your code** - Explain what each sprite does
5. **Debug** - If something breaks, check the last thing you changed
